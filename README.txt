ElectroCalc PWA 1.0
===================
Toate fișierele trebuie încărcate împreună în directorul rădăcină al unui website HTTPS (de exemplu GitHub Pages sau Netlify).
Pe iPhone: deschide adresa HTTPS în Safari → Partajare → Adaugă la ecranul principal.
Pe laptop: deschide aceeași adresă în Chrome/Edge, apoi folosește opțiunea Instalare aplicație.
După prima încărcare online completă, aplicația funcționează offline.
Datele sunt stocate local pe fiecare dispozitiv, fără sincronizare între dispozitive.
Avertisment: valorile termice și căderea de tensiune sunt orientative; necesită proiectare/verificare profesională înainte de execuția instalației.
